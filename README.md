# 台灣保險裁判與評議案例

公開檢索 2020 年起與保險相關的法院及金融消費評議中心文書，提供理賠分類、結果趨勢、已整理摘要及官方來源連結。

## 網站

[開啟理賠爭議儀表板](https://mary793130544-stack.github.io/insurance-cases/?view=1&tab=claims)

## 資料範圍

- 資料快照日期：2026-10-08；目前收錄 228,368 筆文書索引。
- 理賠項目含 PRP、失能、剖腹產、疾病／意外認定等；支援公司多選與人壽／產險篩選。
- 此為官方關鍵字查詢命中的文書索引，不代表全台完整案件母體。同一紛爭可能有多份文書。
- 趨勢僅使用可判讀結果；未知結果及缺少金額均保留缺值。
- 未經逐篇人工校閱的內容標示為官方原文自動節錄；法院裁判與評議決定分開列示。
- 公開網站顯示上次更新時已備妥的內容。尚未整理全文者提供官方索引及原文連結，不會在訪客開啟時即時擷取。
- 本輪歷史回補涵蓋 2020–2024 年，沒有重新查詢 2025–2026 年；各來源實際最新日期請看網站「資料範圍」。

## 發布方式

GitHub Pages 由 `.github/workflows/publish.yml` 發布。兩份 `snapshot.json.gz.part*` 是完整資料快照的壓縮分段，未抽樣、未刪除案件。發布時由 `prepare_site.py` 還原，核對檔案大小及 SHA-256，再部署至 Pages。

更新時一併替換 `index.html`、`data-app-build.json` 及兩份壓縮分段。請勿將本機快取、帳號憑證或其他個人檔案上傳至此公開專案。
